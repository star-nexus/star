# E10 Statistics history container research

Default remains the original array policy. Private native `_set_statistics_history_mode("deque")` selects only the instance window Statistics history; `"baseline"` transfers it back. Invalid names fail before touching the instance. Successful reset restores baseline; failed reset retains both logical data and owner. No schema/API version changes or Python convenience interface.

`StatisticsHistory` owns optional `VecDeque<serde_json::Value>`. On the first actual append, the array is moved out of `GameStats.unit_observation_history`; its slot stays an empty array, and all history access goes through the storage adapter. Zero-append batches keep the original array until that first append. Full export overlays an owned logical array without changing the live storage. Existing presentation/HUD do not transport this history; ordinary observation/host/statistics/combat/telemetry accesses other GameStats fields. The singletons map is not a complete export when research deque storage is active: use Runtime.export.

Rows stay independent owned JSON values, including imported extra fields. Appends precede final window trim. A failed row leaves the same successful prefix untrimmed, and preserves the existing cycle/error boundary. Legacy non-window per-row >10000 to 5000 trimming, visibility history, E2 dispatch threshold128 and native default1 remain unchanged. No deferred destruction: discarded records are dropped during the same trim.

PROFILE=false reads no clocks/counters. Diagnostic trim consumes removed values first, timing iterator+Value destruction, then drops the exhausted Drain, timing retained-array relocation or deque head bookkeeping. Extra diagnostic loop/timer overhead means these are explanatory instrumentation, not performance measurements. `history_retained_slots_relocated` is the container operation model (retained array slots, not deep JSON bytes), not a hardware copy counter. Commit includes history append/transfer; subtract these only for diagnostic attribution, trim remains separately timed as before.
