# E12：权威执行与展示解耦研究

以下保留 E12 首轮私有 `_AuthorityExecutor` 的机制研究记录；当时普通 NativeSession、GameScene、Hub、协议及默认路径未接入。2026-10-10 用户授权正式采用后，现有 Rust 场景默认接入独立 authority owner，详见 [正式实现与回退](native-authority-scheduling.md)。Hub 等既有未接入范围保持。继承 native1、API18/schema5、census 与 E11 默认地形编码复用。

当前主循环每帧接纳本地请求后执行输入、step、增量提取/应用、显示准备、绘制、SDL提交与限帧等待。E12先区分这些等待来源，不把旧性能数字当当前结论。

原型将既有 RustRuntime 的调用权独占转移至一个 Python owner 线程，运行同一个已安装 release 扩展，未新增 Rust 线程池。宿主仍负责给出确定的请求、输入、tick 和展示栅栏顺序；执行器没有自己的时间步或接纳策略。UI 主线程持有派生 World 和 SDL。

JSON输入在接纳前冻结；已接纳 FIFO 操作不可取消。取增量按操作序列写入不可变 JSON publication，附连续 sequence/epoch/revision/tick。UI按序解码应用，每项只消费一次。不合并/丢弃增量或事件。实例独占缓存不跨实例转移。输出队列满时阻塞owner；这会重新产生请求等待，必须量化，不能无界积压。研究默认 inbox32、delta8只用于有界机制验证，不是生产参数结论。

reset先消费旧epoch所有publication；待消费时私有入口拒绝reset，不改变Runtime。原reset失败保留旧状态；成功reset之后宿主必须新建对应展示World并获取新完整baseline。close先关闭接纳，执行已接纳前缀，归还尚未消费增量，再join；宿主必须消费返回增量才可声称展示/事件完整。执行器异常join、停止接纳并向未执行Future报告失败，不自动重启。

VLM需要额外屏障，使图像、阵营视图与权威revision一致，本原型提前拒绝VLM而不访问图像。本限制只属于未接入的私有研究入口，普通协议能力保持。也尚未接入本地交互、Hub发送/结算、生产reset/stop，不能称已证明完整宿主等价。

研究固定测试量：一次有效分解的10秒预热+30秒当前窗口诊断；9项机制契约；固定短输入前400tick(native1)+前20tick(native4)串行/owner逐操作比较，完整权威哈希流式落盘。后续受控等待筛选预注册后才运行，不自动上线、不更新容量/Frontier或关闭既有GAP。完整长轨迹、像素/VLM与真实网络验收属于后续接入审查。

## 本轮结果与后续边界

当前窗口的1014次本地观测周期排队均值16.0009ms，ENV实际观测服务1.1588ms。该诊断包含本地合成负载，不是生产网络接收日志。合并观测/动作周期的等待暴露中，64.10%处于限帧，22.34%处于展示/绘制；因此优先研究独立权威接纳，而非只把绘制计算换线程。

9机制契约通过；native1前400tick/3139请求/467观测、native4前20tick/2073请求/49观测同序比较通过。所有完整authority检查与原wire/响应/事件、展示增量和确定性消费命令一致，消费者apply成功且查询顺序一致。仅验证前缀，没有完整新宿主、像素、VLM和交互生命周期证明。

模拟UI释放GIL的12ms阻塞，300tick ABBA中请求排队27.2872→1.5887ms（94.18%），P99 100.3287→5.1632ms；响应完成28.3549→2.7310ms。全部压力normal，完整结果/增量/末状态一致。等待改善95%区间[93.72%,94.48%]来自仅3个100tick输入块，不宣称多轮稳定。Python busy12ms的100tick控制对照25.7319→4.4772ms，说明GIL会限制收益。模拟等待不是SDL提交，busy不是完整绘制。

进程CPU时间约增加10.72%，native调用墙钟服务均值1.0678→1.1423ms（约慢6.98%）；调度原型的复制/序列化/Future开销没有消失，P2使用默认自动GC，与P0有限epoch GC延迟不同。收益是减少等待而非加速世界计算。

决定继续保留研究入口，默认仍关闭。下一阶段需定义实际请求接收/tick线性化与录制、封闭全部UI写入旁路、同revision的VLM图像屏障、真实窗口与网络适配、结算/reset/stop/队列背压，然后才可以验收宿主净收益。不能把本轮94%当生产延迟或整帧收益；原GAP/容量/Frontier不变，5000Agents暂缓。
